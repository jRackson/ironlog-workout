Automatic progressive overload

When on, IronLog updates each exercise's weight and rep target for you after every workout.

How progression works

  1. Complete all your sets for an exercise and hit the rep target on every set: next time the target is one rep higher.
  2. Once every set reaches the top of the rep range, the weight goes up by that exercise's jump and reps reset to the bottom of the range.
  3. If you miss the target, the same weight and target repeat.
  4. If you fall below the bottom of the rep range two sessions in a row, the weight drops about 10% so you can build back up.
  5. Exercises you skip or only partly finish don't change.

The weight you actually log is what counts, so lifting heavier or lighter than the target simply moves your baseline.

Backup & data

IronLog stores your plan and logs in Safari storage on this iPhone. Back up regularly: the share sheet lets you save the file to Files, iCloud Drive, email or AirDrop.

Install on iPhone

  1. Host the included files on an HTTPS website.
  2. Open that website in Safari on your iPhone.
  3. Tap Share → Add to Home Screen → Add.
  4. Open IronLog from the new Home Screen icon.

A ZIP file alone cannot install a web app directly. See README.txt for the simplest hosting route.
